# 內容矩陣入門

建立內容支柱、拉新／信任／行動／關係矩陣，並整理六個優先製作的 IG／Threads 貼文主題。

## 安裝

下載完整儲存庫，將資料夾命名為 `content-matrix-starter`，放入目前環境支援的個人技能目錄。已有舊版時先備份並原地更新，保留 `SKILL.md`、`agents` 與 `references`。

## 使用

> 使用內容矩陣 skill，依我的品牌資料規劃內容，並生成寫作任務卡。

選定題目後可將任務卡交給長短文寫作技能，沿用受眾、素材與目的，不必重新填表。

## 寫作任務卡交接

使用 [統一任務卡格式](references/task-card.md) 交接資料；未知項目保留待確認，避免把假設當成事實。
## 共用品牌資料

啟動時會先讀取使用者指定的品牌檔、目前對話已確認的同品牌檔案，或目前內容專案根目錄的 `brand-profile.md`，沿用已知品牌、服務與受眾。找不到檔案時仍可繼續，只詢問必要資訊；多品牌無法判斷時先確認。

只有明確要求「更新品牌資料」或「存到 brand-profile.md」才保存，寫入前先讀取並備份既有檔案，完成後回報位置。「從零開始」或「不沿用品牌資料」會跳過自動讀取。

`brand-profile.md` 是個人內容專案的資料，不是技能安裝檔。本儲存庫不包含你的私人品牌資料，保存也不等於授權發布到 GitHub。

範例：

> 使用這個技能，沿用目前專案的品牌資料。

> 將這次確認的服務與受眾更新到品牌資料。
